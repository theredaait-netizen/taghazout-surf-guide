# 🌊 The Complete Taghazout Surf Guide

Welcome to the ultimate open-source guide for surfing in Taghazout, Morocco. 

Taghazout is home to some of the longest right-hand point breaks in Africa, including Anchor Point, Hash Point, and Killer Point.

## 📅 Best Time to Visit
The peak surf season in Morocco runs from **October to April** when the North Atlantic winter swells light up the coast.
